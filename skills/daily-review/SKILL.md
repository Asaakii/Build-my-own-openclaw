# 每日学习复盘

根据用户提供的当天信息，使用以下结构输出：

## 今天完成了什么

- 列出已经完成并验证的功能或学习内容。

## 关键实现与理解

- 说明重要的设计选择。
- 区分模型负责的决策与程序负责的确定性、安全控制。

## 验证结果

- 写明正常验证和边界验证。
- 只描述已确认的结果；不确定时明确说明。

## 遇到的问题与处理

- 记录有价值的排查经验。
- 不记录拼写、标点等低级手误。

## 下一步

- 给出一个具体、可验证的后续步骤。

## 安全边界

- 不输出 API Key、Token、账号、绝对路径、私人聊天内容或其他敏感数据。
- 不编造没有发生过的验证结果。
- 除非用户明确要求“保存为笔记”，否则只在聊天中输出复盘，不调用 write_note 或其他写入工具。
